# אשף ההקמה — `business.md` + `competitors.md` + טוקן Apify

רץ פעם אחת, בריצה הראשונה. שלושה חלקים, לפי הסדר.

## 1. טוקן Apify (חוסם — בלעדיו אין נתונים)

בדוק אם `APIFY_TOKEN` קיים ב-`.env` ותקף (בדיקת החיבור ב-`references/apify.md`).

אם לא — **לעולם אל תבקש מהמשתמש להדביק את הטוקן בצ'אט.** במקום זה:

1. צור `.env` עם השורה `APIFY_TOKEN=` (אם אינו קיים) וודא שהוא ב-`.gitignore`.
2. **פתח את הקובץ למשתמש בעורך** (`open .env` במק / `notepad .env` בווינדוס / `code .env` אם יש VS Code).
3. אמור: "פתחתי לך את הקובץ. הדבק את הטוקן אחרי סימן השווה, שמור, ותגיד לי *מוכן*.
   (הטוקן: apify.com → Settings → Integrations → Personal API token. חשבון חינמי מספיק.)"
4. כשהמשתמש מאשר — קרא את הקובץ והרץ את בדיקת החיבור. אל תציג את ערך הטוקן חזרה בצ'אט.

אם המשתמש בכל זאת הדביק טוקן בצ'אט — שמור אותו ל-`.env` והמשך, אבל הסבר במשפט
שלהבא עדיף בקובץ, כי מה שנכתב בצ'אט נשאר בהיסטוריית השיחה.

## 2. העסק (מסלול מהיר קודם)

אם יש אתר/פרופיל — שאב מהם כמה שיותר לפני ששואלים. השלם רק את החסר:

1. **מה העסק מוכר, במשפט אחד?**
2. **מי הלקוח הטיפוסי?**
3. **מה אזור השירות?** (קובע את רדיוס חיפוש המתחרים)
4. **מה הפרופילים שלך ברשתות?** (אינסטגרם לפחות — הוא נכנס להשוואה כשורה הראשונה)
5. **באיזו רשת להתמקד?** ברירת מחדל: אינסטגרם. אפשר להוסיף טיקטוק/פייסבוק.

## 3. המתחרים

**מי המתחרים שאתה כבר מכיר?** שמות עסק או פרופילים. אפשר "לא יודע — תמצא":
חיפוש רשת לפי תחום+אזור → הצגת 5–8 מועמדים עם הפרופיל שאותר → המשתמש מסמן.
לכל מתחרה מאושר: משיכת פרופיל בודדת לאימות (קיים? ציבורי? זה באמת הם?).

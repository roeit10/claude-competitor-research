# מחקר מתחרים ברשתות ב-10 דקות — Claude Code Skill

Skill ל-Claude Code שמושך דרך Apify את הפרופילים והפוסטים האחרונים של המתחרים
שלך ברשתות החברתיות, ומחזיר דוח השוואה בעברית: כמה הם מפרסמים, באילו פורמטים,
מה באמת עובד להם — ואיפה שלוש הזדמנויות התוכן שלך.

**כל מספר בדוח מגיע מהדאטה, עם קישור.** מה שלא נמשך — מסומן "לא נבדק", לא מומצא.

---

## מה מקבלים בסוף ריצה

- **טבלת השוואה** — הפרופיל שלך מול 3–5 מתחרים: עוקבים, פוסטים לשבוע, תמהיל
  פורמטים (רילז/קרוסלות/תמונות), ומעורבות **מנורמלת לעוקבים** — ההשוואה ההוגנת היחידה.
- **פרופיל לכל מתחרה** — המספרים + 3 הפוסטים החזקים שלו עם קישורים + פילוח
  הנושאים שעובדים לו.
- **שלוש הזדמנויות תוכן** — מנוסחות כפעולה עם המספרים שמאחוריה.
- **בריצה חוזרת: "מה השתנה מאז"** — שינויי תדירות, פורמטים חדשים, קצב צמיחה.

---

## מה צריך

1. **Claude Code** מותקן.
2. **חשבון Apify חינמי** (apify.com) — הקרדיט החודשי החינמי מספיק בשפע;
   ריצה טיפוסית עולה סנטים. הסקיל מסביר בהתקנה איך מעתיקים את הטוקן.

זהו. בלי חיבורי ג'ימייל/דרייב, בלי כלים נוספים.

## התקנה ושימוש

1. פותחים Claude Code בתיקייה שבה תרצו לעבוד.
2. מדביקים את הלינק לריפו וכותבים: **"תתקין לי את הסקיל שנמצא כאן בפרויקט הנוכחי"**.

```
# פעם אחת — טוקן Apify + פרטי העסק + רשימת מתחרים
"תכין אותי למחקר מתחרים"

# ואז, מתי שרוצים
"תריץ לי מחקר מתחרים"
```

לא יודעים מי המתחרים? אומרים "תמצא לי" — הוא מציע לפי תחום ואזור, ואתם מסמנים.

## מה הסקיל לא עושה

- **לא ממציא מספרים.** תדירות ומעורבות מחושבות מהפוסטים שנמשכו בפועל, וכל משיכה
  חלקית מדווחת בקול.
- **לא נכנס לפרופילים פרטיים** ולא מנתח אנשים — רק את התוכן העסקי הציבורי.
- **לא מוריד תמונות וסרטונים** — עובד על נתונים וכיתובים בלבד.
- **לא שורף קרדיטים.** 30 פוסטים אחרונים לפרופיל כברירת מחדל; זה עונה על
  "מה עובד להם עכשיו".
- **לא מדרג "מי הכי טוב"** — משווה ממדים; ההכרעה שלכם.
